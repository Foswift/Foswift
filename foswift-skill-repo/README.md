# Foswift Company Skill

A skill for OpenClaw that provides comprehensive information about Foswift company and products.

## Skill Structure
- `skills/foswift-company-info/SKILL.md` - Main skill file

## Skill Content
- Company background and founder information
- Product line details (T850, MINI, large)
- Technical advantages and features
- Target customer profiles
- Value propositions and pricing
- Sales channels and international strategy

## Usage
This skill can be used by AI assistants to provide accurate information about Foswift company when users ask about:
- Foswift products
- Photography equipment
- E-commerce photography solutions
- Product photography technology
