# 对话记忆系统

## 系统说明

这是一个自动化的对话记录系统，用于永久保存 AI 与用户的所有对话历史。

## 文件结构

```
chat-history/
├── README.md           # 本文件
├── 2026-03-25.md      # 2026年3月25日的对话
├── 2026-03-26.md      # 2026年3月26日的对话（如适用）
└── ...
```

## 记录格式

每个日期文件包含：
- **会话信息**: 日期、会话类型、主题
- **对话内容**: 按时间顺序记录每条消息
  - 用户消息：带时间戳和引用
  - AI 回复：完整内容
- **系统说明**: 对话过程中的重要系统操作

## 使用方式

### 1. 自动保存
每次对话结束后，AI 会自动将对话内容追加到当天的 `.md` 文件中。

### 2. 查询历史对话

你可以用以下方式查询：

**查看某一天的对话：**
```
请查看 2026-03-25 的对话记录
```

**搜索特定内容：**
```
搜索我们讨论过"记忆库"的所有对话
```

**查看最近的对话：**
```
查看最近 3 天的对话记录
```

**查看特定主题：**
```
查看关于"摄影"的所有讨论
```

### 3. 搜索能力

AI 可以：
- 按日期搜索
- 按关键词搜索
- 按主题搜索
- 跨文件搜索整个对话历史

## 数据持久化

- 所有文件保存在工作空间 `/workspace/projects/workspace/chat-history/`
- 你可以随时备份这个文件夹
- AI 拥有完整的读写权限，可以维护这些记录

## 隐私说明

- 这些对话记录仅保存在你的本地电脑上
- AI 可以读取这些记录以便提供更好的上下文
- 数据不会被上传到云端（除非你明确要求）

## 维护

AI 会自动：
- 创建新的日期文件
- 追加对话内容
- 保持文件格式一致性
- 定期整理和优化
