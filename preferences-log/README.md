# 用户偏好档案 - 使用说明

## 🎯 系统目的

这是一个**智能增量学习系统**，用于：
- ✅ 永久记录你的所有偏好
- ✅ 自动学习你的使用习惯
- ✅ 记录常用指令和模式
- ✅ 确保永不丢失

## 🔄 增量学习机制

### 工作原理

**每次对话结束后，AI 会自动：**

1. **检测新的模式**
   - 分析你使用的指令类型
   - 识别你的语言习惯
   - 记录你的决策偏好

2. **更新偏好档案**
   - 新的偏好 → 添加到档案
   - 冲突的偏好 → 标注并确认
   - 强化已有偏好 → 增加权重

3. **增量优化**
   - 不覆盖，只追加
   - 保留历史变化
   - 形成学习轨迹

### 学习触发条件

**自动触发：**
- 你说"我喜欢这样..."
- 你说"不要这样做..."
- 你重复某个指令3次以上
- 你明确表达偏好

**手动触发：**
- "记住我的偏好"
- "更新我的档案"
- "记录这个习惯"

## 🔧 配置选项

### 学习灵敏度
- **高**：任何细微变化都记录
- **中**：明显的偏好才记录（默认）
- **低**：只有明确表达才记录

### 更新频率
- **实时**：每次对话后立即更新（默认）
- **批量**：每天晚上统一更新
- **手动**：只在你要求时更新
