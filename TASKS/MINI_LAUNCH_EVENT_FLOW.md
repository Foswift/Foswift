# MINI佛手光发布会流程设计
## 乔布斯式紧凑发布结构（8-10分钟）

---

## 📋 整体原则（第一性原理）

### 核心目标
1. **粉丝期待** → **信任背书** → **痛点共鸣** → **产品揭晓** → **功能征服** → **价格震撼** → **情感共鸣**
2. 每一个环节都要有一个"Wow"时刻
3. 不讲废话，只讲有用

### 节奏设计
- **开头1分钟**：回应粉丝期待
- **2分钟**：建立信任（T850成就）
- **5分钟**：征服用户（产品功能+场景）
- **最后2分钟**：价格震撼+情感升华

---

## 🎬 详细流程脚本

### 第一部分：开场悬念（0:00-1:30）

#### 画面
- 黑屏背景
- 只有一个产品轮廓（剪影），打光神秘
- 老刘站在产品旁边，穿着简单干净

#### 口播
```
很多粉丝在问我：老刘，MINI什么时候出？
今天，我要告诉大家，MINI来了。

15年摄影，我一直在思考一个问题：
为什么拍好一张产品图，非要40分钟？
为什么非要学灯光、学布光、学修图？
为什么不能像按快门一样简单？

今天，我要给大家看一个东西。
（停顿3秒，指向剪影）
它可能改变一切。

大家好，我是老刘。
```

#### 设计意图
- 直接回应粉丝期待，建立连接
- 数字对比（15年、40分钟）制造冲击
- 问题钩子，引发共鸣
- 悬念设置，不露全貌

---

### 第二部分：信任背书（1:30-3:00）

#### 画面
- 快速展示T850产品全貌
- 展示T850的应用场景（电商团队、摄影工作室）
- 展示客户使用T850的成果（高质量产品图）

#### 口播
```
大家都认识我们的T850。
它帮助了很多电商团队、摄影工作室，
解决了产品拍摄的效率问题。

有人问我，老刘，T850这么好，为什么不早点出MINI？
因为T850证明了，我们的技术是可行的。
我们的15年摄影经验，是可以被固化的。

T850的成功，给了我们信心。
MINI，就是我们为更多用户准备的。

什么用户？
那些需要更小空间、更灵活、更便携的用户。
```

#### 设计意图
- 用T850成就建立信任和权威
- 自然过渡到MINI，不是"新产品"，而是"为更多用户准备"
- 暗示MINI是T850技术的延续和升级

---

### 第三部分：痛点直击（3:00-4:30）

#### 画面
- 切换到场景演示
- 分屏对比：传统拍摄vs佛手光

#### 口播
```
我们电商卖家每天都在拍图。
首饰、小五金、化妆品、美食产品。

传统方式是什么？
搭个静物台，上灯光，调角度，拍完还要修图。
小批量不划算，大批量来不及。
想出去拍？设备搬不动。

我见过太多卖家，
因为拍不出好图，错过最佳销售时机。
因为请不起美工，产品图一直上不了架。

这不合理。
（加重语气）
这不合理。

拍张图，不该这么难。
```

#### 设计意图
- 痛点直击，引发共鸣
- 场景化描述，让用户代入
- "这不合理"重复，强化情绪

---

### 第四部分：产品揭晓（4:30-6:30）

#### 画面
- 产品全貌揭晓
- 拉近镜头，展示细节
- 快速展示折叠、展开过程
- 展示灯光、模式切换

#### 口播
```
所以，我们做了这个。
（展示产品）
MINI佛手光。

先看尺寸。
展开后，65乘67厘米。
（展示放在普通桌子上）
一张普通家庭桌子，就能放得下。
不需要3乘3米的摄影棚，
不需要2.5米的高度。
就在你家里，就在你办公室。

再看折叠。
（展示折叠过程）
就这么一折，厚度变成20.5厘米。
65乘67乘20.5厘米。
放进汽车后备箱，带到客户那里去拍。

想出去拍？说走就走。

（展示灯光）
重点来了。
T850是不带灯光的，MINI配齐了灯光。
而且，是两种模式。

（展示标准光模式）
标准光模式，适合普通产品。
（展示天幕光模式）
天幕光模式，适合首饰、高反光产品。
一键切换，无需调试。

（展示产品尺寸）
可以拍摄30厘米以内的产品。
首饰、化妆品、小五金、美食。

而且，它是电动的。
匀速旋转，正反转动，速度可调。
一键出图，专业品质。
```

#### 设计意图
- 产品揭晓达到期待顶峰
- 详细介绍参数，让用户清楚了解产品
- 对比T850和MINI，突出MINI的优势
- 双模式、灯光、折叠，每个都是卖点
- 电动版突出专业性和易用性

### 第五部分：功能征服（6:30-9:30）

#### 场景1：首饰拍摄（1分钟）
#### 画面
- 实拍一枚戒指
- 切换到天幕光模式
- 展示旋转效果
- 展示白底效果

#### 口播
```
先看这个。一枚戒指。
（切换天幕光模式）
切换到天幕光模式。
（操作）
放上去，按开始，10秒。
（展示效果）
纯白底，360度，专业质感。

没有反光，没有过曝。
首饰的细节，完全保留。

没有后期，没有修图。
拍完就是这个样子。
```

#### 场景2：美食拍摄（1分钟）
#### 画面
- 实拍一个蛋糕或寿司
- 切换到标准光模式
- 展示灯光效果
- 展示多角度

#### 口播
```
再看看这个。一个蛋糕。
（切换标准光模式）
标准光模式，美食质感最好。
（操作）
放上去，旋转，多角度。

（展示效果）
美食的质感，灯光的层次，一看就有食欲。
餐饮店老板，你们懂的。

做好的菜，放上去，拍完直接上外卖平台。
不再需要专业摄影师，不再等待拍摄时间。
```

#### 场景3：外出拍摄演示（30秒）
#### 画面
- 展示折叠过程
- 展示放入汽车后备箱
- 展示在客户现场拍摄

#### 口播
```
想出去拍？
折叠，20.5厘米厚度，放进汽车后备箱。
去客户那里拍，去活动现场拍，去户外拍。

想在哪里拍，就在哪里拍。
灵活，就是这么简单。
```

#### 场景4：速度对比（30秒）
#### 画面
- 分屏对比
- 左边：传统方式40分钟
- 右边：佛手光10秒

#### 口播
```
传统方式，40分钟。
佛手光，10秒。
（加重语气）
40分钟，vs，10秒。

这不是效率，这是革命。
```

#### 设计意图
- 用4个具体场景证明产品价值
- 重点展示美食拍摄场景（餐厅、外卖平台）
- 突出双模式（标准光、天幕光）
- 突出外出拍摄场景（客户现场）
- 速度对比制造视觉冲击
- "这不是效率，这是革命"强化颠覆性

### 第六部分：价格震撼（9:30-10:30）

#### 画面
- 产品全貌特写
- 老刘表情真诚

#### 口播
```
很多人会问，这么强大的产品，多少钱？

我知道，市面上有些静物台卖几百块。
但那是材料，不是技术。
不会转，不会自动出图，也没有我们的技术支持。

MINI佛手光，我们卖的是什么？
卖的是15年的摄影经验。
卖的是一键出图的技术。
卖的是专业级别的品质。
卖的是1年的技术支持服务。

而且，配齐了灯光，双模式，电动旋转。
（加重语气）
带出去就能拍，放家里就能用。

这样的产品，你会觉得多少钱？
（停顿3秒）

价格，我们会在3月31日揭晓。
但我可以告诉你，它会让所有人惊喜。

不是惊喜我们卖得贵。
是惊喜，我们卖得太值。
```

#### 设计意图
- 价格悬念保持到发布日
- 对比"材料vs技术"强化价值主张
- 强调"配齐灯光、双模式、电动旋转"
- "惊喜我们卖得太值"制造期待

## 📌 拍摄注意事项

### 画面风格
- 简洁干净，不花哨
- 产品特写要清晰
- 场景切换要流畅
- 背景用纯色，突出产品

### 老刘表现
- 眼神真诚，不装
- 语速适中，重点加重
- 停顿要自然，制造节奏
- 不说废话，只讲有用

### 背景音乐
- 开头：神秘、悬念
- 中间：节奏感强
- 结尾：温暖、情感化

### 剪辑原则
- 每个环节不超过2分钟
- 功能演示用快剪
- 特写产品细节
- 保持节奏紧凑

## 📝 更新说明（第二次优化）

### 新增要点

#### 1. 粉丝期待（开场）
- 直接回应"老刘，MINI什么时候出？"
- 建立与粉丝的连接感

#### 2. T850成就（信任背书）
- 用T850的成功证明技术可行性
- 自然过渡到MINI：不是新产品，而是为更多用户准备

#### 3. MINI核心参数（产品揭晓）
- **占地尺寸**：65*67cm（普通桌子就能放）
- **折叠尺寸**：65*67*20.5cm（放入汽车后备箱）
- **灯光配置**：T850不带灯光，MINI配齐灯光
- **双模式**：标准光模式（普通产品）+ 天幕光模式（首饰、高反光产品）
- **产品尺寸**：可拍摄30cm以内产品

#### 4. 场景演示（功能征服）
- **场景1：首饰拍摄**（天幕光模式）
- **场景2：美食拍摄**（标准光模式，餐厅、外卖平台）
- **场景3：外出拍摄**（客户现场、户外）
- **场景4：速度对比**（40分钟vs10秒）

### 调整要点

1. **总时长**：控制在10分钟左右（原来是8-10分钟）
2. **环节**：从6个增加到7个
3. **场景**：从3个增加到4个，重点增加美食拍摄场景
4. **参数**：详细展示MINI的核心参数和优势
5. **信任**：用T850成就建立背书，不是凭空推出MINI

### 核心逻辑（第一性原理）

**问题**：很多用户已经认识佛手光，对MINI有期待
**本质**：不需要"从头介绍产品"，而是"用T850背书+MINI参数征服"
**颠覆**：MINI不是"小号T850"，而是"为更多用户准备的专业解决方案"
**价值**：让电商卖家、餐厅老板、自媒体人员，都能自己拍出专业图
