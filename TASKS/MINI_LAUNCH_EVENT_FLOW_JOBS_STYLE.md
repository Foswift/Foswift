# MINI佛手光发布会流程设计（乔布斯式演讲）
## 老刘演讲+PPT演示+最后展示成品（10-12分钟）

---

## 🎯 整体风格（乔布斯式发布会）

### 核心特征
1. **大屏幕PPT**：简洁、文字少、图片大、数字对比醒目
2. **老刘演讲**：站在屏幕旁，手势丰富，停顿有节奏
3. **逐步揭晓**：先理念、后参数、最后实物
4. **视觉冲击**：每一页PPT都有"Wow"时刻
5. **最后高潮**：拿出成品，现场演示

### 场景设置
- 老刘站在屏幕左侧
- 大屏幕右侧播放PPT
- 老刘穿简单干净的衣服（黑色或深色）
- 背景简洁，不抢戏

## 🎨 PPT设计原则

### 视觉风格
1. **简洁干净**：黑底白字，或白底黑字，不花哨
2. **文字少**：每页不超过3个要点，每句不超过15个字
3. **图片大**：产品图占页面80%以上
4. **数字醒目**：重要数字用超大字号（40-60号）
5. **对比强烈**：用颜色突出重点（红、绿、蓝）

### 排版规则
1. **居中对齐**：主要文字居中，突出重点
2. **留白充足**：页面不拥挤，每页留30%空白
3. **字体统一**：标题用粗体，正文用常规
4. **图标清晰**：用✅❌⚡等图标，增强视觉冲击

### 动画效果
1. **淡入淡出**：切换页面用淡入淡出，不用花哨动画
2. **视频自动播放**：演示视频自动播放，无需点击
3. **节奏控制**：每页停留时间与演讲节奏匹配

## 🎬 老刘表现要点

### 站姿和手势
1. **站姿稳定**：站在屏幕左侧，身体微侧向观众
2. **手势丰富**：指向屏幕、手掌摊开、双手握拳
3. **眼神交流**：看镜头，不看屏幕
4. **停顿自然**：重要内容前后停顿2-3秒

### 语速和节奏
1. **语速适中**：比平时说话稍慢，清晰有力
2. **重点加重**：关键句子加重语气
3. **停顿制造节奏**：每页PPT演讲后停顿1秒
4. **情绪递进**：开场悬疑→中间理性→结尾激情

### 穿着和形象
1. **衣服简洁**：黑色或深色，不花哨
2. **头发整齐**：干净利落
3. **精神饱满**：眼神真诚，微笑自然
4. **不戴配饰**：避免干扰

## 📋 拍摄和剪辑要求

### 拍摄设置
1. **机位固定**：正对老刘，全身+大屏幕同框
2. **光线充足**：老刘和屏幕光线均匀
3. **背景简洁**：纯色背景，不抢戏
4. **录音清晰**：领夹麦克风，保证音质

### 剪辑原则
1. **节奏紧凑**：每页PPT停留时间与演讲匹配
2. **切换流畅**：PPT切换与演讲同步
3. **视频嵌入**：演示视频在PPT中播放，不需剪辑
4. **结尾高潮**：拿出MINI的瞬间，给特写
