## 📅 2026年4月上半月重要更新（历史记录）

### 1. 淘宝/天猫发货管理规范调整（2026-04-09生效）
**生效时间**：2026年4月9日逐步生效
**公示时间**：2026年4月2日
**核心变更**：
- **赔付比例调整**：承诺发货时间大于48小时的商品，商家在承诺时效内自主承认缺货，赔付比例由15%调整为10%
- **适用条件**：
  - 商家主动服务消费者，明确告知缺货原因
  - 与消费者协商达成一致
  - 通过平台工具向消费者进行赔付
- **不适用情况**：承诺发货时间≤48小时的商品，赔付比例仍为10%
- **目的**：鼓励商家主动沟通，降低经营成本，尤其适合预售及长发货时效类商家

### 2. "其他物流公司"发货治理（2026-04-20起逐步执行）
**公示时间**：2026年4月3日
**执行时间**：2026年4月20日起根据类目逐步下线
**核心变更**：

- **变更前**：开放全行业实物类目商品使用

- 利用错放类目，将商品发布在有权限类目
- 存在虚假发货、物流轨迹异常等发货违规行为
- 使用"其他物流公司"发货引发消费者批量投诉、负面舆情或平台资损
- 实际使用有物流轨迹信息回传的物流商发货，但商家选择"其他物流公司"点击发货

### 3. 超级立减活动规则调整（2026-04-01生效）
**生效时间**：2026年4月1日
**核心变更**：
#### 调整一：价格门槛收紧
活动期间，商品的标价/普惠券后价，不能高于：
1. 该商品 + 店内同款商品 近15天内的最低标价/最低普惠券后价
2. 举例：商品A的SKU活动价729元，但系统识别到另一个商品B存在一模一样的同款SKU，其最低券后价为599.28元，那么商品A该SKU的活动价必须 ≤ 599.28元，才能报名

#### 调整二：动销要求上线
1. 商品近60天动销件数 ≥ 1件，方可参与
2. **例外情况**：
   - 新品
   - 60天内新上架商品
   - 特殊类目（如书籍/杂志/报纸）

#### 生效范围特别提醒：
- 规则对【新报名商品】和【已报名成功的超级立减活动商品】同时生效
- 已经在活动中的商品，也会被回溯校验，不符合要求可能被清退

### 4. 淘宝平台价格管理规则（2026-09-20生效）
**生效时间**：2026年9月20日
**公示时间**：2026年9月12日

- **系统自动计算**：商品券后价、折后价将淘金币、红包等用户个人资产会纳入优惠计算，并在商品详情页中以系统自动计算、实时更新的方式进行展示
- **处罚措施**：如果商家在主图设计了不符合要求的价格说明，平台将会对价格说明相关的内容予以"AI擦除"，此外还有警告、经营权限管制、违约金和扣分等

### 5. 商品体验分限制（2026-09-24生效）
**生效时间**：2026年9月24日
**核心变更**：
- 商品活动报名时，商品体验分为60分以下的将被限制参加营销活动
- 这意味着如果商品体验分没有达到60分，商家将无缘双十一、双十二等大促活动
- 商品体验分从商品差评、物流延迟发货、缺货、非主观原因退款及消费者求助平台问题这几个维度进行评定，得分区间为0-100分

### 6. 退款规则升级（2026-02-15生效）
**生效时间**：2026年2月15日零点起逐步实施
**核心变更**：
- **自动秒退范围扩大**：
  - 淘宝店铺：小于等于500元的订单（子订单）
  - 天猫店铺：任意金额订单
- **系统自动处理**：在消费者付款后且商家未发货前，系统将自动进行"未发货秒退款"处理，无需商家再有额外操作
- **例外情况**：虚拟、订制等特殊类目除外
- **影响**：
  - 降低商家处理售后的操作成本
  - 提升退款挽留率：秒退的消费者在24小时内购买同商品的概率是等待12小时再退款的2.5倍

### 5. 淘宝平台直播交易争议处理规则（2026-03-25）
**生效时间**：2026年3月25日

**核心内容**：
#### 第一节 通用规则
1. **约定优先**：卖家或主播与买家就交易商品或服务有约定的，优先从约定；未约定或约定不明的，双方可协议补充；无法达成补充协议的，淘宝将按照本规则进行处理

2. **卖家责任**：直播交易发生的争议，经淘宝认定属于卖家或主播责任的，由卖家先行承担履约、协商、举证、退款、运费等责任。若是因主播违反平台要求或跟卖家的约定导致的争议，卖家向买家承担责任后可向主播/机构等追偿

3. **举证责任**：因直播交易发生的争议，经淘宝认定需查看直播回放的，应由卖家承担相应的举证责任，包括但不限于直播视频回放链接、直播时间等。如卖家提供无效的直播回放或未能提供直播回放的，交易支持退货退款

4. **七天无理由**：直播交易的商品按淘宝公示的相关规则须支持七天无理由退、换货的，主播在直播过程中单方或跟买家约定不支持七天无理由退、换货的行为无效，交易按照七天无理由退、换货相关规则执行

5. **描述不一致**：主播应当按照卖家商品详情页的描述或与卖家约定的承诺进行直播，若主播在直播间的描述或承诺与卖家的描述或承诺不一致时，以有利于买家的描述或承诺为准

6. **未履行承诺**：主播在直播过程中的承诺（如赠品、优惠活动等）未履行的，卖家应履行相应承诺或与买家协商一致，否则交易支持退货退款

**典型违规案例**：
- 直播间说明秒杀款不退不换，但商品符合七天无理由退货条件，商家拒绝退货，纠纷介入后支持消费者退货退款，且会计入店铺退款纠纷率
- 主播说明买手机送价值100元的充电宝，消费者收到商品后发现赠品是一个手机壳，买家申请退款，商家拒绝，纠纷介入后支持买家的维权申请，且会计入店铺退款纠纷率

## ⚠️ 一般违规行为

### 1. 滥发信息
发布不实、夸大或误导性的商品信息

**处罚**：
- 商品降权
- 下架
- 扣分

### 2. 虚假交易
通过虚构交易或刷单等方式提高商品销量或信誉

**2026年新规严厉打击**：
- **低价单无效化**：单价低于1元或低于3折的订单，销量不累计、评价不显示
- **乱改SKU=自杀**：任意修改商品核心属性（如品类、功能），该商品所有历史销量直接清零
- **"无货源"模式濒死**：首次违规即面临保证金罚没、全店商品下架、搜索降权30天的重罚。二次违规，店铺基本无法经营

**处罚**：
- 销量清零
- 下架商品
- 搜索降权
- 保证金罚没

### 3. 延迟发货
未在规定时间内完成发货

**2026年新规**：
- 发货后48小时无物流更新，系统将自动向消费者赔付
- 钱从保证金里扣

**处罚**：
- 扣分
- 影响体验分
- 自动赔付

### 4. 描述不符
商品描述与实际不符，误导消费者

**2025年12月新规**：
- 主图用高端款，发的是低配版
- 文案写"进口原料"，实际是国产
- 直接用AI生成图或盗图冒充实拍
- 消费者投诉货不对板且成立，平台将直接支持仅退款，还会影响店铺品质分

**处罚**：
- 商品降权
- 下架
- 支持仅退款
- 影响品质分

### 5. 违背承诺

### 6. 竞拍不买
