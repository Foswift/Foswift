## 专利法

### 中国专利法概述

#### 专利类型
1. **发明专利**
   - 保护期：20年
   - 审查制：需要实质审查
   - 保护范围：技术方案（产品、方法）

2. **实用新型专利**
   - 保护期：10年
   - 初步审查制
   - 保护范围：产品的形状、构造

3. **外观设计专利**
   - 保护期：15年
   - 初步审查制
   - 保护范围：产品的外观设计

#### 专利申请条件
1. **新颖性**：不属于现有技术
2. **创造性**：与现有技术有实质性区别
3. **实用性**：能够制造或使用

#### 专利申请流程
```
提交申请 → 初步审查 → 公布 → 实质审查（发明） → 授权 → 缴纳年费
```

#### 专利权内容
- 发明专利：实施专利的权利
- 实用新型专利：实施专利的权利
- 外观设计专利：实施外观设计的权利

#### 专利侵权判定
- 相同侵权
- 等同侵权
- 禁止反悔

## 商标法

### 中国商标法概述

#### 商标类型
1. **商品商标**：用于商品
2. **服务商标**：用于服务
3. **集体商标**：用于集体组织
4. **证明商标**：用于证明商品或服务

#### 商标注册条件
1. **显著性**：便于识别
2. **不冲突**：不与他人商标相同或近似
3. **不违法**：不违反法律法规

#### 商标注册流程
```
提交申请 → 形式审查 → 实质审查 → 公告 → 授权 → 缴纳年费
```

#### 商标权内容
- 独占使用权
- 许可使用权
- 续展权

#### 商标侵权判定
- 相同或近似商标
- 类似商品或服务

## 著作权法

### 中国著作权法概述

#### 著作权类型
1. **文字作品**：文字、论文、代码等
2. **艺术作品**：图片、视频、音乐等
3. **软件著作权**：计算机程序
4. **其他作品**：建筑设计、产品设计等

#### 著作权保护期
- 个人作品：作者终生+50年
- 法人作品：50年
- 软件著作权：50年

#### 著作权内容
- 人身权：署名权、修改权等
- 财产权：复制权、发行权、信息网络传播权等

#### 著作权侵权判定
- 未经授权的使用
- 未支付报酬
- 歪曲、篡改

## 常见问题

### Q：专利申请需要多长时间？
A：发明专利一般需要2-3年，实用新型和外观设计专利需要6-12个月。

### Q：专利申请需要多少钱？
A：发明专利申请费约9000元，实用新型约1500元，外观设计约1000元。还需要律师费、年费等。

### Q：专利保护期限多长？
A：发明专利20年，实用新型10年，外观设计15年。

### Q：如何判断是否有侵权风险？
A：需要检索现有专利，分析是否侵犯他人专利权。

### Q：商标注册需要多长时间？
A：一般需要12-18个月。

### Q：商标注册需要多少钱？
A：一个类别约300元，每增加一个类别增加300元。还需要代理费等。
