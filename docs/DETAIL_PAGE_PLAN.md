## 🚀 快速开始

### 方案1：立即使用（仅ffmpeg）
```bash
# 1. 准备产品图文件夹
mkdir -p ~/foswift_images
# 将产品图放入该文件夹

# 2. 批量处理
cd ~/foswift_images
for file in *.jpg *.png; do
  ffmpeg -i "$file" -vf scale=750:-1 -q:v 2 "detail_$file"
done
```

### 方案2：完整方案（推荐）
```bash
# 1. 安装ImageMagick
sh /tmp/install_imagemagick.sh

# 2. 使用Python脚本
cd /workspace/projects/workspace/tools
python3 detail_page_generator.py

# 3. 修改脚本中的路径
input_dir = "/path/to/your/product/images"
output_dir = "/path/to/output"
```
