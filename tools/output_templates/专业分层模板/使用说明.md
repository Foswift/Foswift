## 编辑方法

### 修改文字
1. 在图层面板找到对应文字图层
2. 双击图层缩略图
3. 或使用文字工具（T）直接点击文字
4. 修改内容即可

### 替换图片
1. 找到"可替换"图层
2. 使用移动工具将新图片拖入
3. Ctrl+T 调整大小
4. 或 File → Place 嵌入图片

### 修改颜色
1. 双击图层缩略图
2. 在颜色面板选择新颜色
3. 或使用油漆桶工具填充

### 删除/隐藏元素
1. 选中图层
2. 按 Delete 删除
3. 或点击眼睛图标隐藏

## Photoshop操作技巧

### 快速定位图层
- 按 V 切换移动工具
- 点击图像自动选中图层

### 显示/隐藏图层
- 点击眼睛图标切换
- Alt+点击 单独显示

### 复制图层
- Ctrl+J 复制选中图层

### 合并图层
- Ctrl+E 向下合并
- Ctrl+Shift+E 合并可见图层

### 调整图层顺序
- 拖拽图层上下移动

## 常见问题

Q: 为什么图层重叠？
A: 上方图层遮住下方是正常的，点击眼睛切换显示

Q: 如何单独查看一个图层？
A: Alt+点击眼睛图标

Q: 导出的图片有白边？
A: File → Trim → Transparent Pixels

Q: 找不到图层？
A: 图层面板顶部搜索框输入名称
