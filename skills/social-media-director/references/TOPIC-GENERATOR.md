# 话题生成器

## 没灵感时？从这里找！

### 方式1：热点追踪（时效性强）

**每天必看：**
- 抖音热榜Top 20
- 微博热搜榜
- B站热门视频
- 行业垂直网站新闻
- 小红书热门笔记

**热点切入角度：**

**角度1：不同观点**
```
热点：某明星离婚
→ 你的观点：为什么明星离婚率这么高？
→ 普通人如何避免踩坑？
→ 婚姻经营的核心是什么？
```

**角度2：深度解析**
```
热点：某公司裁员
→ 深度：行业周期与个人选择
→ 给职场人的3个建议
→ 如何在不确定环境中生存
```

**角度3：情感共鸣**
```
热点：加班猝死事件
→ 共鸣：为什么我们不敢停下来？
→ 职场人的自我救赎
→ 健康与工作的平衡之道
```

**角度4：实用建议**
```
热点：ChatGPT火了
→ 实用：如何用AI提升工作效率？
→ 新人如何应对AI时代？
→ 推荐这些AI工具给你
```

### 方式2：粉丝问题库（持续积累）

**收集方式：**
- 每条视频评论区翻看
- 微信/私信收集问题
- 竞品评论区挖掘
- 知乎/小红书相关问题

**问题分类存储：**

```markdown
## 职场类
- 如何在职场中不被边缘化？
- 同事甩锅怎么办？
- 面试怎么谈薪资？
- ...

## 效率类
- 每天事情做不完怎么办？
- 如何克服拖延症？
- 工作专注力如何提升？
- ...

## 成长类
- 25岁开始学习还来得及吗？
- 如何快速进入一个新领域？
- 读了很多书为什么记不住？
- ...

## 情绪类
- 工作压力大怎么办？
- 如何摆脱焦虑情绪？
- 总是自我怀疑怎么办？
- ...
```

**每周更新：**
- 周末整理本周收集的问题
- 选择高频问题做内容
- 问题回答后标记"已解决"

### 方式3：主题发散（稳定输出）

**从一个大主题，发散出10个小主题：**

**主题：工作效率**

```
1. 时间管理类
   - 番茄工作法实用指南
   - 四象限法如何应用
   - 每日计划怎么做

2. 工具推荐类
   - 提升效率的APP推荐
   - 办公软件隐藏技巧
   - 免费AI工具大盘点

3. 心态调整类
   - 如何保持工作状态
   - 拖延症的自救指南
   - 焦虑情绪管理

4. 方法论类
   - PDCA工作法
   - 复盘的重要性
   - 如何持续精进

5. 场景应用类
   - 会议效率提升
   - 邮件快速处理
   - 多任务切换技巧

6. 痛点解决类
   - 经常被打断怎么办
   - 工作做不完的原因
   - 精力管理比时间管理重要

7. 案例分析类
   - 高效人士的日常习惯
   - 名人的时间管理
   - 我是如何提升效率的

8. 避坑指南类
   - 时间管理常见误区
   - 效率工具的坑
   - 这些方法别再信了

9. 对比分析类
   - 时间管理工具对比
   - 不同方法适合什么人
   - 职场新人vs老手的效率差异

10. 综合指南类
    - 完整的一天工作流
    - 新人效率提升30天计划
    - 从0到1建立工作体系
```

**应用建议：**
- 每月选择一个大主题
- 10个小主题覆盖全月
- 每周2-3条内容
- 留出2-3天做热点/粉丝问答

### 方式5：反向内容（争议性强）

**反向思维：**

```
正观点：努力就能成功
→ 反向：为什么你努力了还没成功？
→ 原因分析：方向不对、方法错误、平台有限

正观点：多学技能总没错
→ 反向：技能学了太多反而没用
→ 建议：专注核心技能，深度优于广度

正观点：早起效率高
→ 反向：熬夜党怎么提升效率？
→ 方法：找到自己的黄金时段

正观点：社交很重要
→ 反向：无效社交毁了你
→ 建议：断舍离，建立高质量社交
```

**注意事项：**
- 反向是为了引发思考，不是唱反调
- 要有合理论证
- 给出建设性建议
- 避免过于偏激

## 紧急方案

**今天真的没灵感？**

**方案1：翻评论找灵感（5分钟）**
- 打开最近10条视频
- 查看评论区高频问题
- 选择一个问题做回答
- 形式："大家问最多的XX问题，今天统一回答"

**方案2：工具/方法分享（10分钟）**
- 打开常用工具APP
- 选一个你常用的功能
- 录屏演示+口播解说
- 形式："99%的人都不知道的隐藏功能"

**方案3：竞品借鉴（15分钟）**
- 找到同领域优质博主
- 看最近热门内容
- 换个角度重新演绎
- 加上你的独特观点

**方案4：日常分享（5分钟）**
- 记录今天的一件小事
- 分享你的思考/感悟
- 形式：日常vlog碎片
- 关键：真实、有细节

**方案5：预告下周内容（5分钟）**
- 列出下周要分享的内容
- 提前预告引发期待
- 评论区征集问题

## 话题质量评估

**打分维度（每项0-10分）：**

1. **新颖度**（0-10分）
   - 是否有新角度/新观点？
   - 是否有新信息？
   - 是否有别处没说过的？

2. **实用性**（0-10分）
   - 对用户是否有用？
   - 能否解决实际问题？
   - 是否能立刻应用？

3. **共鸣度**（0-10分）
   - 是否触动情绪？
   - 是否让用户觉得"这就是我"？
   - 是否引发讨论？

4. **传播性**（0-10分）
   - 是否容易被分享？
   - 是否有金句可传播？
   - 是否有争议性？

**总分≥30分可以做，≥35分优先做，<30分放弃**
