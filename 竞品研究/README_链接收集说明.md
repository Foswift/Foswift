## 如何获取真实商品链接

### 步骤1：搜索商品
1. 打开淘宝网站 (taobao.com)
2. 在搜索框中输入对应的"搜索词"（如"春季新款"）
3. 按销量排序，找到热销商品

### 步骤2：获取链接
1. 点击进入商品详情页
2. 复制浏览器地址栏中的完整URL
   - 示例：`https://item.taobao.com/item.htm?id=1234567890`
3. 这个链接就是可以直接跳转到商品页面的真实链接

### 步骤3：填写到表格
1. 打开`竞品链接收集模板.csv`
2. 将复制的链接粘贴到对应的"商品链接"列
3. 保存文件
